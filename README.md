# 卷不死

卷不死桌面客户端的安装包。这里只放发布的安装包和更新信息，不放源代码。

在 [Releases](https://github.com/juanbusi-org/juanbu/releases/latest) 下载最新版本：

| 系统 | 文件 |
| --- | --- |
| macOS（Apple 芯片和 Intel 通用，已签名并经 Apple 公证） | `juanbu-macos-universal.zip` |
| Windows 10 / 11（Intel / AMD） | `juanbu-setup-windows-amd64.exe` |
| Windows on ARM | `juanbu-setup-windows-arm64.exe` |
| Linux | `juanbu-linux-amd64.tar.gz` / `juanbu-linux-arm64.tar.gz` |

装好后卷不死会自己检查并下载新版本。每个版本附带的 `latest.json` 由发布者签名，卷不死只接受签名正确的更新。
